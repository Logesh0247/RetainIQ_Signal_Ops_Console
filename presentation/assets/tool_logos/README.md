# Technology-stack marks

The slide embeds these PNG exports in its left-side tool rail. The Simple Icons
SVG sources for Python, Pandas, Scikit-learn, Flask, FastAPI, Docker and GitHub
are from <https://github.com/simple-icons/simple-icons> (CC0 1.0). The Power BI
SVG source is from Microsoft's <https://github.com/microsoft/PowerBI-Icons>
repository. These marks are shown only to identify the tools used in RetainIQ;
respective names and logos remain trademarks of their owners.

The exported PNGs use transparent backgrounds for the dark Signal Ops theme.
